# Portfolio HTML e CSS

Ciao, sono **Francesca Cudemo**, Junior UX/UI Designer. Questo è il mio portfolio personale, realizzato per l'esame con HTML, CSS (Sass) e Bootstrap.

🔗 **Sito online:** https://TUO-USERNAME.github.io/portfolio-html-css/

## Pagine

- `index.html`: home con presentazione, competenze e progetti
- `cv.html`: curriculum vitae scritto in HTML
- `contattami.html`: form di contatto

## Tecnologie

- HTML5 e CSS3
- Sass (partial, variabili, mixin)
- Bootstrap 5
- Flexbox e CSS Grid
- Design responsive su desktop, tablet e mobile
- JavaScript solo per l'invio del form di contatto

## Struttura del progetto

```text
├── index.html
├── cv.html
├── contattami.html
├── scss/        # sorgenti Sass
├── css/         # CSS compilato
└── assets/      # immagini, favicon, script del form
```

## Compilare il Sass

```bash
npm install
npm run sass
```
