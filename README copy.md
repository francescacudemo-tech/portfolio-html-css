# Portfolio — Francesca Cudemo

HTML + CSS (Sass) + Bootstrap 5 (CDN). Target: studi di design, aziende e recruiter che cercano una Junior UX/UI Designer.

## Compilare Sass
```
npm install
npm run sass      # oppure: npm run watch
```
Il file `css/main.css` incluso è già compilato, ma **ricompilalo con Sass vero prima della consegna**.

## Da sostituire prima di pubblicare (cerca nei file)
- `TUO-USERNAME` → il tuo username GitHub (link GitHub e URL dei tag Open Graph in `index.html`, `cv.html`, `contattami.html`)
- `assets/img/profile.jpg` → la tua foto (quadrata, almeno 800×800)
- `cv.html` → i segnaposto evidenziati (`.todo`): esperienza, formazione, lingue
- `assets/js/contact.js` → chiavi EmailJS (opzionale; senza chiavi il form apre il client di posta)

## Pubblicare su GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` / root.
L'URL sarà `https://TUO-USERNAME.github.io/NOME-REPO/`.
